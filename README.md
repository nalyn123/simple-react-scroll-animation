# simple-react-scroll-animation

> Made with create-react-library

[![NPM](https://img.shields.io/npm/v/simple-react-scroll-animation.svg)](https://www.npmjs.com/package/simple-react-scroll-animation) [![JavaScript Style Guide](https://img.shields.io/badge/code_style-standard-brightgreen.svg)](https://standardjs.com)

## Install

```bash
npm install --save simple-react-scroll-animation
```

## Usage

```jsx
import React, { Component } from 'react'

import MyComponent from 'simple-react-scroll-animation'
import 'simple-react-scroll-animation/dist/index.css'

class Example extends Component {
  render() {
    return <MyComponent />
  }
}
```
